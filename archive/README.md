# Archive

This directory contains earlier versions of the SecurePass Validator project that were retained for historical reference.

These files document the project's evolution during development and are no longer part of the production-ready application.

The current implementation is located in the repository root and includes:

- `main.py`
- `validator.py`
- `blocklist.py`
- `password_history.py`
- `hash_manager.py`

These archived files are preserved for educational purposes and to demonstrate the progression of the project over time.
